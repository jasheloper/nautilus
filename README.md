# nautilus
Web Dev Take Home Assessment 2026

## Goal of assessment: 
To assess your skills in basic HTML, CSS, and Javascript to build a standard specials page from a Figma mock-up, while also seeing your ability to upload content. Please try to complete this assignment in under an hour and half.

## Extra Credit: 
While not required, if you finish this assignment and have some extra time, feel free to add functionality to the disclaimer button, so that a disclaimer modal pops up when “OFFER DETAILS >” is clicked. (the modal should be closeable)

## How to create and provide the project:
Create a local file to create a live version of the Mock-Up, using:
HTML
CSS
Javascript 

Export the images provided to you in the “Assets” section of the Figma file to use in your assessment. 

When complete, please zip all files and attach them here in our chat. If you are unable to add them here, please share a Google Drive link, if neither of those works, please provide it in a GitHub Repository.
The zipped file should contain:
Your completed .html file
Any images or other linked assets
